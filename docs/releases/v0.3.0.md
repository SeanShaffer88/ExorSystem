# ExorSystem 0.3.0

## Before you upgrade

**Close ExorSystem and back up the entire `%LOCALAPPDATA%\ExorSystem` profile**, including the database and quarantine directory. The first launch upgrades the database to schema v5. The automatic pre-migration SQLite copy does not include held files. If you need to return to v0.2.0, keep a separate copy of the upgraded profile and restore the full pre-upgrade profile while ExorSystem is closed; do not open the schema v5 profile in the older app.

If you are upgrading from v0.1.0, also keep any old `data` folder beside the executable. The desktop does not import that folder or its quarantine automatically.

## What's new

- **Review exact files before cleanup.** A cancellable, read-only preflight shows which paths are included or excluded. Approval applies only to that plan. ExorSystem rechecks the application registration, file identities, and eligibility before moving files. Registry, service, and task findings remain advisory.
- **Verify held files and profile copies.** Make a verified profile backup, restore it to a separate directory, or free local space by rotating a batch only after checking its archived copy. Restore never overwrites an existing file. An interrupted purge does not resume on startup. Quarantine uses same-volume Windows moves; cross-volume paths are refused.
- **Compare and revisit Watch results.** Save scope presets, cancel a capture, reopen recent comparisons, and see which scopes were compared or skipped—even when there were no changes. Strict file comparison can rehash content rather than reusing hashes based on unchanged size and timestamps.
- **Find and export evidence.** Filter History by change type, path, installation, and UTC dates. Save matching observations as JSON with a continuation for older rows. Sort Applications and page through session evidence or a recorded quarantine batch.
- **Desktop refinements.** The Activity log attaches below the workspace. Native pickers, bounded capture work, and clearer progress make long operations easier to manage. Closing ExorSystem waits for safe completion when necessary and does not terminate vendor uninstallers.

## Windows downloads

Choose the **NSIS installer** (`-Setup.exe`), **MSI**, or **portable ZIP**. All are Windows x64. Compare the downloaded file's SHA-256 with `SHA256SUMS.txt` from the same release. `PACKAGE-CHECKS.json` records the exact source and static package checks. These checks do not install or launch the packages on Windows 10/11 clients and do not verify recovery after a real power loss.

No kernel driver is bundled or needed. Desktop Watch does not use the experimental live sources.
