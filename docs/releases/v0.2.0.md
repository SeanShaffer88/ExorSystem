# ExorSystem 0.2.0

## Before you upgrade from 0.1.0

**Back up the old `data` folder beside `ExorSystem.exe`, including any quarantine batches.** The desktop now runs as a normal user and stores its database and quarantine under `%LOCALAPPDATA%\ExorSystem`. It leaves the old data unchanged and does not import old history or offer to restore old batches. It also refuses to start if launched as Administrator. Installing or uninstalling a machine-wide package may still prompt for UAC separately.

## What's new

- **Inventory and leftover review:** Browse classic Windows programs and current-user MSIX packages, or register portable apps explicitly. Only supported machine-wide classic registrations can start their uninstallers in ExorSystem. Use Windows Settings for per-user apps and uninstallers that need elevation. Registry, service, and task matches are advice only.
- **Driverless Watch and History:** Watch selected file folders and optional registry subtrees. Finish a watch to open its session in History, including recorded removals, source labels, a path filter, and older pages. Snapshots show what changed between checks, not which process did it.
- **Safer quarantine:** Restore never replaces an existing file. Interrupted batches are recovered when safe, and conflicting held files are kept for review. Both cleanup paths roll back failed database writes; restore and purge reject redirected storage.

## Windows downloads

Choose the **NSIS installer** (`-Setup.exe`), **MSI**, or **portable ZIP**. All three are x64. Before running a package, compare its SHA-256 with the copy of `SHA256SUMS.txt` attached to the same release. `PACKAGE-CHECKS.json` records static checks and the source commit; the Windows 10/11 client test results are separate.

No registry driver is bundled or needed. The optional USN and registry-driver sources are not enabled in the desktop.
