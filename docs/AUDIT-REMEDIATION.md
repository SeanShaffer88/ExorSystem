This describes the unreleased changes based on `97d2f45b33a082a1b5bc0fbc1267a1fdba79ae86`. The CI and package evidence in [AUDIT.md](../AUDIT.md) describes prior code, not these changes. Nothing here changes the already-published v0.2.0 artifacts.

## Limits to keep visible

- One cleanup preflight can inspect up to eight roots and 4,096 findings; a plan can include at most 512 files and read up to 2 GiB for fingerprinting. Review pages contain up to 40 paths. The native controller keeps two inactive drafts for up to ten minutes, discarding the oldest; changing a file or the selected registration requires a new plan. Cleanup writes only files that were approved, never registry keys or empty folders.
- Watch accepts up to eight folder scopes. Per-scope limits are 24,000 inspected entries, 8 MiB of paths, and 2 GiB of hashing reads; aggregate file bounds are 48,000 entries, 16 MiB of paths and 4 GiB of scheduled hashing. Limits, inaccessible probes and unhashable files must be visible; they are not evidence of absence. Scans and scope attempts aren't instantaneous snapshots of Windows.
- Backup caps are 40,000 indexed files, 64 GiB, and a 16 MiB index. Storage measurements are logical profile sizes, not actual disk allocation. Cleanup summary shows recorded sizes for its displayed page; Overview covers the latest 40 batches, and session pickers show the latest 150 sessions. The underlying History and retained records are not truncated by the picker limit.
- Windows same-volume moves preserve streams by renaming the existing file. Cross-volume moves fail closed. Archive is a byte-verified profile copy, not a system image, not a complete installation backup or a promise of any program's restorability. Backups, reports, and storage directories are not hardened against arbitrary modification by other software with the same user's permissions.

## Local results

- **Passed:** production GUI build, 36 WCAG AA theme contrast checks, and the four Chromium suites using the built bundle and mocked IPC. The suites exercise approval, cancellation, backup, rotation, dated export continuation and close feedback, alongside the existing desktop and docking regressions.
- **Passed in a source-tag Linux harness:** 125 Rust tests, including simulated interruption and DB failure, stale file identity, changed held bytes, backup tampering, and UTC cursor boundaries. Clippy passed with the `chunks_exact_to_as_chunks` lint allowed on the harness's Rust 1.99.0. Both workspace format checks and `git diff --check` passed.
- **Not run:** a successful build or license check with the pinned locked dependency set. The sandbox could not fetch the required registry crates. Windows-only tests, native Tauri/Win32 compilation, and interactive package checks remain pending.
